# 25 コメント分析

## 目的
視聴者の生の声を、次の企画・ネタ・台本に活かし、本人の返信の手間を減らす。

## 入力情報
- 本人が共有したコメント・DM（テキストまたはスクリーンショット）
- 投稿記録（23）

## 作業手順
1. コメントを分類する：悩み／質問／共感・感想／要望／その他。
2. 繰り返し出る悩みや質問を、ネタの種として抜き出す。
3. 返信の下書きを作る（落ち着いたトーン。診断・治療にあたる返答はしない。強い症状には受診をすすめる）。
4. 個人を特定できる情報は記録に残さない。

## 出力形式
- `projects/<フォルダ>/25-comment-analysis.md`
- 分類表（分類｜要約｜件数）、ネタの種リスト、返信下書き（コメント要約｜下書き）

## 完了条件
- 共有された全コメントが分類され、必要なものに返信下書きがある。

## 引き継ぎ事項
- 視聴者分析（05）・テーマ選定（06）へ：ネタの種と悩みの言葉。改善提案（27）へ：反応の傾向。

## やらないこと
- 返信の送信（本人）。
- 診断・治療にあたる返答の下書き。
- 数値の分析（数値分析26の範囲）。
