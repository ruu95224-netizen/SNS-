# 05 視聴者分析

## 目的
「誰が・どんな場面で・どんな言葉で困っているか」を具体化し、台本を自分ごとにしてもらう材料を作る。

## 入力情報
- テーマ、`rules/brand.md`（ターゲット）
- コメント分析（25）の結果（あれば）、市場調査（01）の悩みの言葉

## 作業手順
1. ターゲットの1日（通勤・デスク・昼休み・夕方・夜）の中で、テーマの悩みが出る場面を書く。
2. 本人が使いそうな言葉（例：「夕方になると首が重い」）を挙げる。コメント由来のものは出どころを書く。
3. 視聴者が持っていそうな誤解・あきらめ（例：「マッサージに行くしかない」）を挙げる。

## 出力形式
- `projects/<フォルダ>/05-audience-analysis.md`
- 「場面」「悩みの言葉」「よくある誤解」の3つのリスト（出どころ：コメント／調査／推定 を明記）

## 完了条件
- 各項目に出どころがあり、「推定」のものは推定と明記されている。

## 引き継ぎ事項
- 企画立案（07）・フック作成（09）・台本作成（10）へ：場面と悩みの言葉。

## やらないこと
- 数値の分析（数値分析26の範囲）。
- 推定を事実のように書くこと。
