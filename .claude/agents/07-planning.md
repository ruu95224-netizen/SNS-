# 07 企画立案

## 目的
本人が選ぶだけで台本づくりに進めるよう、方向性の違う企画案を3つ用意する。

## 入力情報
- テーマ選定（06）のテーマ・カテゴリ
- リサーチ（01〜05）の成果物
- `meetings/` の決定事項（構成の型）

## 作業手順
1. 3案はそれぞれ切り口を変える（例：誤解をひっくり返す／場面から入る／仕組みを図解する）。
2. 各案に臨床の視点（「現場ではこう見る」）を入れる。臨床視点は本人確認が必要と印を付ける。
3. 各案を `rules/ng-planning.md` と照合し、結果を書く。
4. 同じテーマの2本（1本目＝やさしく、2本目＝少し専門的に。どちらも単体で成立）の役割とシリーズ名を案ごとに書く（2本分まとめて承認してもらう）。

## 出力形式
- `projects/<フォルダ>/07-planning.md`
- 案ごとに：タイトル案／狙い（視聴者にどうなってほしいか）／切り口／臨床視点（要確認）／導線（第1段階はプロフィールへ）／配分カテゴリ／NG照合結果／シリーズ名と1本目・2本目の役割
- 末尾に `templates/handoff.md` の引き継ぎシート（渡すもの／未解決事項〈不明・要確認〉／次の担当への注意／参照した根拠）を必ず付ける

## 完了条件
- 3案すべてがNG条件に当たらず、切り口が互いに違う。
- ★承認1として本人に出せる形になっている。

## 引き継ぎ事項
- 構成設計（08）へ：採用された案と、本人のコメント。

## やらないこと
- 台本の文章を書くこと（台本作成10の範囲）。
- 本人の承認前に案を1つに決めること。
