# 08 構成設計

## 目的
台本を書く前に「何を、どの順で、何秒で伝えるか」を決め、迷いなく文章化できる骨組みを作る。

## 入力情報
- 企画立案（07）の採用案と本人のコメント
- `rules/brand.md` の構成の型（1本完結リール × ゆるいシリーズ）
- 視聴者分析（05）、競合調査（02）の差別化ポイント

## 作業手順
1. 想定尺を決める（目安を書き、理由を添える。根拠のない「◯秒が伸びる」は書かない）。
2. シーンを割る：フック → 共感（場面） → 意外な事実・誤解の訂正 → 臨床の視点 → 具体的なセルフケア／考え方 → CTA。
3. 各シーンの「伝える1メッセージ」と秒数を決める。
4. 同じテーマの2本では、1本目（共感・やさしい）と2本目（少し専門的な解釈）の分担を書く。**どちらも単体で成立する**よう、2本目にも短い共感の場面を入れる。

## 出力形式
- `projects/<フォルダ>/08-structure-design.md`
- 表：「シーン｜秒数｜伝える1メッセージ｜必要な根拠（あれば）｜画面のイメージ」
- 末尾に `templates/handoff.md` の引き継ぎシート（渡すもの／未解決事項〈不明・要確認〉／次の担当への注意／参照した根拠）を必ず付ける

## 完了条件
- 全シーンが1メッセージに絞られ、合計秒数が想定尺と一致している。

## 引き継ぎ事項
- フック作成（09）・台本作成（10）・タイトル作成（11）・CTA設計（12）へ：骨組み表。

## やらないこと
- ナレーションの文章化（台本作成10の範囲）。
- フックの言葉づくり（フック作成09の範囲）。
