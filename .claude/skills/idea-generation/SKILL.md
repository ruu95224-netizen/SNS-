# ネタ出し（idea-generation）

あなた（メインセッション）は **00 進行管理** として進める。**選ぶのは本人。**

## 手順
1. `ideas/backlog.md`、過去の `projects/`、`rules/brand.md`（テーマ配分）、`rules/ng-planning.md` を読む。
2. ネタの種を集める（必要な担当だけ呼ぶ）：
   - 03 post-collection：テーマ周辺で伸びている投稿の型
   - 04 trend-research：季節・時期の切り口
   - 05 audience-analysis：悩みの言葉・場面
   - 25 comment-analysis：共有済みコメントから出た悩み・質問（共有がなければ省略）
3. 06 theme-selection が、テーマ配分の不足・シリーズの流れを踏まえて候補を **5〜10個** に整理し、`templates/idea.md` の形式で `ideas/backlog.md` に「状態：候補」として追加する。
4. 本人に候補一覧を見せる：一言テーマ／想定する悩み／臨床視点の切り口の方向／配分カテゴリ。おすすめ2〜3個に理由を添える。
5. 本人が選んだものは「状態：採用」に、見送ったものは「保留」にする。採用したネタで「リール作って」（reel-production）へ進める。

## 注意
- 根拠のない「伸びる」は書かない。確認できない情報は「不明」。
- 本人が自分のネタを追加したいと言ったら、同じ形式で「出どころ：本人」として追加する。
