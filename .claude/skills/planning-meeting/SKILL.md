# 企画会議（planning-meeting）

あなた（メインセッション）は **00 進行管理（司会）** として進める。**決めるのは本人。**

## 手順
1. 議題を1文で確認する（例：「リールの構成の型をどうするか」）。
2. 議題に関係する担当を選ぶ。例：
   - 構成の型：01 市場調査・02 競合調査・05 視聴者分析・07 企画立案・08 構成設計・26 数値分析・27 改善提案
   - 指標の切り替え：26 数値分析・27 改善提案・12 CTA設計
   - シリーズ設計：06 テーマ選定・07 企画立案・08 構成設計・05 視聴者分析
3. 各担当を呼び、それぞれの立場から「意見と根拠」を出してもらう。根拠がない効果予測（「保存率が◯%上がる」など）は書かせず「**検証が必要**」とする。
4. `templates/meeting.md` の形式で、案ごとの利点・弱点・検証方法をまとめ、推奨案と理由を書く。
5. `meetings/YYYY-MM-DD-<議題>.md` に保存し、`meetings/README.md` の議題一覧を更新する。
6. 本人に結果を短く見せて決めてもらう。
7. 決定が出たら議事録の「本人の決定」に書き、ルールに反映が必要なら `rule-update` で反映する。
