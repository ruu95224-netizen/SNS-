# 1本目：揉んでも戻るのは、あなたのせいじゃない（81点・差し戻し）

## 採点表
| 項目 | 点数 | 理由 |
|---|---|---|
| 分かりやすさ | 21/25 | 流れ（場面→あなたのせいじゃない→ほぐすのは悪くない→現場では→理由のひとつ）は前提知識なしで追える。ただ、シーン2「あなたの**やり方**のせい」の「やり方」が何のことか分からない（マッサージの受け方？セルフケア？）。シーン5「同じ姿勢や負担が続く毎日が、そのままなこと」は耳で聞くと文の形がこんがらがり、一度では入ってこない |
| 冒頭3秒で続きを見たくなるか | 19/25 | 「また戻る」はターゲットに刺さる問いで方向はよい。ただし4秒あり、3秒の時点ではまだ「…ありませんか？」まで届いていない。「また戻る。…ありませんか？」と文が途中で切れて、耳で聞くと少し不自然。tone.md の「デスク・スマホ・夕方」のような具体的な場面がフックに入っておらず、「自分のことだ」と思うきっかけが弱い |
| 臨床視点（一般論で終わっていないか） | 18/25 | 「理学療法士の現場では〜を聞きます」は現場らしさがあって良い。ただ「聞きます」で止まり、聞いて**何が分かるのか**がない。シーン5の「同じ姿勢・同じ負担が続く」はそれだけだと「知ってた」と思われやすい一般論。シーン4とシーン5がつながっていないため、「現場の見方から出てきた考え」に聞こえない |
| トーン（落ち着き・やわらかさ） | 23/25 | 煽りなし、「〜なんです」のやわらかい断定、（間）の位置も適切で、tone.md によく合っている。減点は、シーン4が1秒6字以上でいちばん詰まっていて、ここだけ早口に聞こえやすい点 |
| **合計** | **81/100** | **差し戻し** |

## 離脱ポイント
| 位置 | 離脱しそうな理由 |
|---|---|
| 0〜3秒（フック） | 3秒で問いが言い終わらない。画面の文字（「マッサージでラクになったのに、また戻る？」）を先に読み終えた人は、ナレーションを待たずに流しやすい |
| 15〜21秒（シーン4） | 「どんな作業をどれくらい続けているかを聞きます」で終わり、答えがない。「で？」となったところで、詰まり気味の早口が重なる。いちばん離脱しやすい |
| 21〜27秒（シーン5） | 結論が「同じ姿勢が続くこと」で、聞いたことのある話に聞こえる。「知ってる」と思った人はCTAの前に離れる |
| 27〜30秒（CTA） | 「シリーズは」と言われても、何のシリーズか耳では分からない（画面上部の小さな表記だけが頼り）。プロフィールを見に行く理由がない |

## 修正案（10へ）
1. **フックを3秒に収め、場面を入れる**。「…ありませんか？」の切れた形をやめる。例：「揉んでもらったのに、また肩が重い？」（約15字）。言葉づくりは09のフック案から選び直してもよい。
2. **シーン2の「やり方の」を削る**。「揉んでも戻るのは、あなたのせいではないんです」にして画面テキストと同じにする（短くなり、秒数も空く）。
3. **シーン4とシーン5をつなぐ**。シーン4で「聞く」だけでなく、シーン5の冒頭を「聞いてみると、」「話を聞くと見えてくるのが、」のようなつなぎで始め、「現場で聞いた結果、見えてくるもの」としてシーン5を言う。例：「聞いてみると、（間）ほぐしたあとも、同じ姿勢の毎日が続いている。それが、戻る理由のひとつなんです。」※臨床の見方（C）の言い回しが変わるので、14の確認と★承認2での本人確認が要る。
4. **シーン4を短くする**。「どれくらい」を削り、時間は画面のカードで見せる（10の削り候補どおり）。例：「理学療法士の現場では、ほぐしたあとの過ごし方を聞きます。」
5. **CTAに「何のシリーズか」を入れる**。12の1-Cのままだと耳で伝わらない。CTAを4秒にして、例：「戻る理由のシリーズは、プロフィールからどうぞ。」（約22字）。12の決まり（「続きは」「次回」は使わない・量を言わない）は守ること。
6. **秒数の配分案**（合計30秒）：フック3／共感5／誤解の訂正6／臨床の視点5／考え方7／CTA4。直したら文字数と秒数の表も更新する。

# 2本目：ほぐすとラクなのに、戻りやすいのはなぜ？（78点・差し戻し）

## 採点表
| 項目 | 点数 | 理由 |
|---|---|---|
| 分かりやすさ | 19/25 | 「原因はひとつではない→今回はふたつ」の組み立ては親切。ただし3つ引っかかる。①「軽い」が2つの意味で出てくる：シーン2「**軽く**なっても」（肩がラク）と、シーン5「**軽い**負担」「**軽く**ても」（負担が小さい）。耳だけだと混ざる。②要素①と要素⑧の違いが分からない：シーン6「座りっぱなしが長い→同じ負担が続きやすい」はシーン5の言い直しに聞こえ、「ふたつ」と言ったのに同じ話を2回聞いた感じになる。③シーン7「作業の続け方」、シーン8「視点を足す」が抽象的で、何を思い浮かべればよいか分からない |
| 冒頭3秒で続きを見たくなるか | 18/25 | 5秒あり、3秒の時点では「ほぐすとラクになるのに、（間）なぜ」までしか聞こえない。問いの中身も1本目とほぼ同じで、「少し専門的な回」らしい引きがない。具体的な場面もフックにない |
| 臨床視点（一般論で終わっていないか） | 19/25 | 「その場から少しの間、と見ています」「硬さだけでなく続け方も見ています」と現場の見方が2か所あり、1本目より臨床らしい。ただシーン7は「何を見るか」の名前だけで、見たときに何に気づくのかがない。シーン3の「と見ています」は主語がなく、誰の見方か（理学療法士としての見方なのか）がシーン7まで分からない |
| トーン（落ち着き・やわらかさ） | 22/25 | 落ち着いていて煽りはない。減点は、シーン3「主（おも）に、その場から少しの間（あいだ）、と見ています」の読点が多くてぶつ切れに聞こえること。シーン3・5・6の文末が「〜んです」で続き、AI音声だと同じ調子がくり返されて単調になりやすいこと。シーン5・7が詰まり気味で早口に聞こえやすいこと |
| **合計** | **78/100** | **差し戻し** |

## 離脱ポイント
| 位置 | 離脱しそうな理由 |
|---|---|
| 0〜3秒（フック） | 問いが3秒で終わらず、1本目と同じ問いに見える。1本目を見た人ほど「同じ話」と思って流しやすい |
| 20〜31秒（シーン5・6） | 「軽い」の意味が混ざり、要素①と⑧が同じ話に聞こえる。「ふたつ」と言った約束が果たされていない感じがして、ここで離れやすい。2本目でいちばん危ない |
| 31〜42秒（シーン7・8） | 「続け方」「視点を足す」が抽象的で、「結局どういうこと？」のまま終わる。具体策を出さない方針（note第1弾の範囲）は正しいが、イメージできる言葉が1つもないのは物足りない |
| 42〜45秒（CTA） | 1本目と同じ文言で、2本目ならではの理由（「やさしい回もある」「まとめて見られる」）を使えていない。何のシリーズかも耳では分からない |

## 修正案（10へ）
1. **フックを3秒に収める**。例A（短くする）：「ほぐすとラクなのに、なぜ戻る？」（約14字）。例B（専門的な回らしさを出す）：「ほぐしても戻る肩こり。（間）理学療法士はこう見ています。」。どちらにするかは09と相談。1本目との違いが出るBを推す。
2. **「軽い」の二重の意味をなくす**。シーン5の「軽い負担」「軽くても」を「小さな負担」「小さくても」などに替える（画面テキストも同じに）。シーン2の「軽くなっても」はそのままでよい。
3. **要素①と⑧の違いをはっきりさせる**。今は⑧が①の言い直しになっている。どちらかで直す。
   - 案a（新しい中身を足さない）：⑧を「①を途切れさせない時間」として言う。例：「ふたつめは、座りっぱなしが長いこと。その小さな負担が、途切れにくいんです。」
   - 案b（元資料7章⑧の「活動量」を使う）：例：「ふたつめは、座りっぱなしで、体を動かす時間が少ないこと。」※主張が少し増えるので14の確認が要る。
   - 13のおすすめは案a（08の範囲から出ないため）。
4. **シーン7を具体的にする**。「作業の続け方」を、1本目で★承認1済みの見方に寄せて、例：「硬さだけでなく、（間）同じ姿勢でどれくらい作業を続けているかも見ています。」（2本の臨床視点もそろう）。※言い回しが変わるので14・本人確認が要る。
5. **シーン3に主語を入れ、読点を減らす**。例：「理学療法士としては、ラクになるのは主にその場から少しの間、と見ています。」シーン7と「理学療法士」が重なる場合は、シーン7を「現場では」だけにする。
6. **文末の「〜んです」を2か所までに減らす**（シーン3・5・6のどれか1つを「〜ます」「〜こと。」止めに）。
7. **CTAを2本目向けにする**。フックを3秒にすると2秒空くので、CTAを5秒にして12のおすすめ2-A（「肩こりが戻る理由は、シリーズでまとめています。プロフィールからまとめて見られます」）か2-B（「やさしい解説の回もあります。プロフィールからどうぞ」）に戻す。締めの**画面**は1本目と共通のまま、ナレーションだけ変える。12の決まり（具体的なケア方法を期待させない）は守ること。
8. **秒数の配分案**（合計45秒）：フック3／共感4／誤解の訂正7／原因は1つではない4／要素①6／要素⑧5／臨床の視点6／考え方5／CTA5。直したら文字数と秒数の表も更新する。
