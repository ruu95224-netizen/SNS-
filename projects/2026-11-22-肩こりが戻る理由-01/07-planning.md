## 案A：誤解をひっくり返す「ほぐれた＝おしまい、じゃない」

- **タイトル案**
  - 1本目：「揉んでも戻るのは、あなたのせいじゃない」
  - 2本目：「ほぐすとラクになるのに、戻りやすいのはなぜ？」
- **狙い**：「ほぐしても戻る」を自分の努力不足と思っている人に、「ほぐすのは悪くない。毎日の負担がそのままだと戻りやすい」と気づいてもらう。プロフィールを見て続きを知りたくなってもらう。
- **切り口**：よくある思い込み「肩こり＝筋肉が硬いだけ。ほぐせば終わり」（05 の M1）をやさしくひっくり返す。
- **1本目の役割（やさしく共感）**：場面は S9（マッサージに行った日はラク→また戻る）。「やり方が悪いわけじゃない」と受け止めてから、「戻る理由のひとつは、毎日の過ごし方（同じ姿勢・同じ負荷が続く）がそのままなこと」という気づきで終える。数値なし。
- **2本目の役割（少し専門的）**：ほぐしてラクになるのは主に「その場〜短い間」という見方と、肩こりは原因が1つではない（多因子性）ことを2要素だけ（7章①持続的な低負荷、⑧長時間の座位）。1本目を見ていなくても、冒頭の問いだけで分かる作り。
- **臨床視点（要確認）**：「現場では、『揉んでも戻る』と言う人には、ほぐした後にどんな作業をどれくらい続けているかを聞くことが多い」という見方。
- **導線**：2本とも締めはプロフィールへ（「肩こりが戻る理由を、プロフィールでまとめています」程度。文言は10が作る）。
- **配分カテゴリ**：肩こり／肩こり
- **NG照合（rules/ng-planning.md）**
  - 副神経の滑走アプローチ：含まない → OK
  - 医療機器の紹介・推奨：含まない → OK
  - 「正しい姿勢を保つ」を解決策にする：しない。姿勢は「同じ負荷が続く」の形でだけ触れる → OK
  - 診断・治療を示す：「戻る理由のひとつ」として扱い、決めつけない → OK
  - 単独の筋肉の問題として説明：「筋肉が硬いだけ」を否定する切り口。2本目で多因子性を明示 → OK
  - 臨床の視点がない：あり（要確認） → OK
  - 根拠の強さを区別しない：数値・研究は使わない（確認後のみ、強さと対象を明記） → OK
  - 強い症状：扱わない。触れる場合は受診を促す一文 → 該当なし
- **注意点**：「ほぐすのは意味がない」と受け取られないよう、「ほぐすのは悪くない」を必ず入れる。

## 案B：場面から入る「休み明け・夕方に戻る肩」

- **タイトル案**
  - 1本目：「休みの日はマシなのに、月曜にまたつらくなる肩こり」
  - 2本目：「デスクで肩こりが戻りやすい、ひとつの理由」
- **狙い**：「戻るタイミング」に自分を重ねてもらい、「戻るのは、その前に何かが続いているからかも」と自分の1日を振り返るきっかけにしてもらう。
- **切り口**：見る人の1日の場面（05 の S11 休み明け、S8 夕方、S3 デスク）から入る。理屈より先に「あるある」で共感をつくる。
- **1本目の役割（やさしく共感）**：場面は S11（休日はマシ→月曜に戻る）と S8（夕方が一番つらい）の2つ。「戻るのは、気のせいでも年のせいでもなく、平日に続いていることがあるのかも」という気づきで終える。数値なし。
- **2本目の役割（少し専門的）**：場面は S3（気づくと同じ姿勢で長くたっている）。「同じ負荷を少しずつかけ続ける」ことと戻りやすさの関係を、7章①（持続的な低負荷）を中心に説明。M6（シンデレラ仮説）は**本文確認できた場合だけ**「という考え方（仮説）がある」として入れる。単体で分かるよう、場面の説明から始める。
- **臨床視点（要確認）**：「現場では、つらくなる曜日・時間帯を聞いて、その前に何が続いていたかを見る」という見方。
- **導線**：2本とも締めはプロフィールへ。
- **配分カテゴリ**：肩こり／肩こり
- **NG照合（rules/ng-planning.md）**
  - 副神経の滑走アプローチ：含まない → OK
  - 医療機器の紹介・推奨：含まない → OK
  - 「正しい姿勢を保つ」を解決策にする：しない。「同じ姿勢が続く」ことを理由のひとつとして扱う → OK
  - 診断・治療を示す：「〜のかも」「理由のひとつ」で決めつけない → OK
  - 単独の筋肉の問題として説明：**注意**。2本目が①（筋の持続的な低負荷）中心のため、「原因は1つではない」の一言を必ず入れる → 条件付きOK
  - 臨床の視点がない：あり（要確認） → OK
  - 根拠の強さを区別しない：シンデレラ仮説は「仮説」と明記、未確認なら使わない → OK
  - 強い症状：扱わない → 該当なし
- **注意点**：2本目の「同じ姿勢が続く」は、06のシリーズ案 #2（姿勢）と重なる。#1では「入口」だけにし、#2で深める（または#2の切り口を変える）。月曜・夕方の「戻る」を事実のように言い切らない（05はすべて推定）。

## 案C：仕組みを図解する「肩の負担の“たまり方”」

- **タイトル案**
  - 1本目：「ほぐしても戻る肩こりを、コップの水でたとえると」
  - 2本目：「肩こりは“肩だけ”の問題じゃない」
- **狙い**：「ほぐす＝負担を一度減らす。でも毎日の負担がまたたまる」というイメージを1枚の図で持ち帰ってもらう。保存したくなる図解で、プロフィール文「肩こりが戻る原因を図解」とつなげる。
- **切り口**：たとえ（コップの水・負担と回復のバランス）と図で、戻る仕組みを見える形にする。
- **1本目の役割（やさしく共感）**：「ほぐしたのにまた戻る」を、コップの水（負担）が減っても、毎日少しずつ注がれるとまたいっぱいになる、というたとえで見せる。**あくまでたとえ**であることを画面に入れる。数値なし。
- **2本目の役割（少し専門的）**：肩こりは原因が1つではない（多因子性）ことを、2要素だけ図で示す（7章①筋の持続的な低負荷、②首と肩甲帯のつながり）。「ほかにもいくつかの見方がある」までにとどめ、一覧は出さない。単体で分かるよう、冒頭で「ほぐしても戻る」の問いを立て直す。
- **臨床視点（要確認）**：「現場では、硬さそのものより、負担のかかり方と、回復できる時間があるかのバランスを見る」という見方（7章①「負荷容量と活動量の不一致」に近い）。
- **導線**：2本とも締めはプロフィールへ。図解に向くので、リール画面を流用したカルーセルを任意で追加できる（会議の決定。作るかは本人判断）。
- **配分カテゴリ**：肩こり／肩こり（2本目は仕組み解説寄りだが、06の配分どおり肩こりで数える）
- **NG照合（rules/ng-planning.md）**
  - 副神経の滑走アプローチ：含まない → OK
  - 医療機器の紹介・推奨：含まない → OK
  - 「正しい姿勢を保つ」を解決策にする：しない → OK
  - 診断・治療を示す：たとえと一般的な見方にとどめ、決めつけない → OK
  - 単独の筋肉の問題として説明：2本目で「肩だけじゃない」を明示 → OK
  - 臨床の視点がない：あり（要確認） → OK
  - 根拠の強さを区別しない：たとえは「たとえ」と明記。研究・数値は使わない → OK
  - 強い症状：扱わない → 該当なし
- **注意点**：図が「全体像」に近づくとnote第1弾と重なる。要素は2つまで、手順・見分け方は描かない。たとえが仕組みそのもののように受け取られないよう注意。図の制作でCanva作業が増える（本人の負担）。
