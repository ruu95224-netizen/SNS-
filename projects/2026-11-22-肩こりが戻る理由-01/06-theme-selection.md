## 4. #1 で扱う範囲

**#1 は「なぜ戻るのか」の入口だけ。全体の答えは出さない。**

| | 1本目（やさしく共感・今日） | 2本目（少し専門的・今週中） |
|---|---|---|
| 扱う | 「揉んでも戻る」の共感（場面は1〜2個。05 の S6・S9 など）。ほぐすのは悪くない。ただ、毎日の過ごし方（同じ姿勢・同じ負荷が続く等）がそのままだと戻りやすい、という気づき | ほぐすと楽になるのは主に「その場〜短い間」という見方と、肩こりは原因が1つではない（多因子性）ことを1〜2要素だけ |
| 根拠 | 数値を使わない構成にする（今日の投稿で、本文確認済みの根拠が0件のため） | 01 の M4（首の痛みへのマッサージのレビュー）・M6（シンデレラ仮説）などは**本文未確認**。確認できるまで台本に入れない。確認できない場合は、数値なしで臨床の視点だけで組む |
| 最後 | 小さな気づき（または誰でもできる一般的な1動作）＋プロフィールへの案内 | 同左 |
| 扱わない | 原因の一覧、自分のタイプの見分け方、具体的なセルフケアの手順・組み立て（note第1弾の有料部分にとっておく）、「本当の理由はこれ」と言い切ること | 同左 |

- マッサージ・整体を否定しない（「無意味」「効かない」と言わない）。
- 「治る」「改善する」と言い切らない。「戻りにくくする」「ラクに過ごす」の範囲で。

## 5. 有料note第1弾との重なりの扱い

note第1弾「マッサージしても肩こりが戻る本当の理由」は、リール#1と同じ題材。リールで中身を出しすぎると、noteを買う理由が減る。

**役割分け（案）**
| | リール（#1） | 有料note第1弾 |
|---|---|---|
| 役割 | 「そういうことか」と気づかせ、プロフィールに来てもらう | 理由の全体像と、自分に合う具体策が分かる |
| 中身 | 問い（なぜ戻る？）と、理由の入口1〜2個 | 9つの視点を通した全体像、見分け方、具体策の手順 |
| 具体策 | 出さない。出すとしても誰でも知っている一般的な1動作まで | ここで初めて出す |

**線引きのルール（案）**
1. リールに出すのは「理由の入口（1〜2要素）」まで。要因をいくつも並べない。
2. 「自分はどのタイプか」の見分け方・チェック方法は出さない。
3. セルフケアの手順・順番・組み立ては出さない。
4. 「本当の理由」という言い方はnoteのタイトルにとっておき、リールのタイトル・フックでは使わない（案）。
5. note第1弾はまだ公開されていないので、リールでnoteへ直接誘導しない（brand.md：noteへの直接誘導は公開後・第2段階で検討）。行き先はプロフィール。

この線引きは本人の判断が必要（要確認）。
