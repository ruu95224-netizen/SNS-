# 承認ルール

最終更新：2026-11-22
※ 変更は rule-update スキル経由・本人承認後に行う。

## 承認なしでやってはいけない作業
| 作業 | 承認のタイミング |
|---|---|
| 企画の採用 | ★承認1 |
| 台本の確定 | ★承認2 |
| 完成版の確定 | ★承認3 |
| 画像生成など、外部ツールでの生成・書き込み | 実行前に毎回 |
| 投稿 | 本人が行う（AIはしない） |
| コメント・DMへの返信送信 | 本人が行う（AIは下書きまで） |
| ルールの追加・変更 | rule-update スキルで変更案を示し承認後 |

## 各承認で本人に見せるもの
- **★承認1（企画）**：企画案3つ（狙い・切り口・臨床視点・導線・配分カテゴリ・NG照合結果）。同じテーマの2本分をまとめて。
- **★承認2（台本）**：完成台本、根拠一覧、**要確認リスト**（臨床視点の確認・根拠不明点）、レビュー点数、表現チェック結果。
- **★承認3（完成版）**：台本・字幕・AI音声設定・素材リスト・図解・Canva編集指示書・品質チェック結果・キャプション案。

## その他
- 差し戻しは最大2回。3回目は本人に相談する。
- 本人が承認を返していないときは、**次の工程に進まず待つ**。
