# 使ってはいけない表現

最終更新：2026-11-22
※ 変更は rule-update スキル経由・本人承認後に行う。表現チェック担当（15）はこの表と照合する。

| NG表現 | 理由 | 言い換え |
|---|---|---|
| 治る／治します | 医療効果の断定（薬機法・信頼） | ラクになりやすい |
| 改善する（断定） | 効果の断定 | 変化を感じる人もいます／ラクになりやすい |
| 必ず／絶対／100% | 根拠のない断定 | 〜しやすい／〜という人が多い印象です |
| 施術10,000人 | 事実と異なる（件数であって人数ではない） | 施術約10,000件 |
| 〇〇するだけで肩こり解消 | 誇大表現 | 〇〇は肩をラクにする一つの方法です |
| 正しい姿勢を保てばOK | 方針と矛盾（姿勢は変えることを重視） | 同じ姿勢を続けないことが大切です |
| 医師も推奨／医学的に証明済み | 出典なしの権威づけ | （出典があれば出典名を明記して述べる） |
| 〜%の人が（出典なし） | 根拠のない数値 | 出典を付ける、または数字を使わない |
| 効く（商品紹介で断定） | 薬機法・景表法 | なぜ肩がラクになりやすいのかを仕組みで説明 |
| 診断します／治療します | 医療行為との線引き | セルフケアの提案です |

## 必須表記
- アフィリエイトリンクや商品紹介を含む投稿・キャプションには毎回「**PR**」または「**広告**」を明記（2023年10月施行のステマ規制）。
