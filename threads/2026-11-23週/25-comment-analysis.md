## 3. 「伸びが悪い」ときに本人が投稿後にできる小さな行動 3つ

### 3-0. 本人への説明（やさしい説明用）
- どれも **1回1分くらい** でできる、小さな行動です。全部やらなくて大丈夫です。
- 返信欄でのやりとりが増えると伸びやすい、という公式の数字や根拠は **確認できていません（不明）**。なので「試してみて、どうだったかを記録する」ための案です。
- 文はそのままコピーして使えます。言い回しは自由に変えてください。
- 送るのは本人です。

### 行動① 投稿の直後に「自分の投稿へ補足の返信」を1つ出す

ねらい：本文を読んだ人が、返信しやすくなる「きっかけ」を返信欄に置いておく。

出し方
- 予約投稿（11時ごろ）が出たら、なるべく早く、**自分の投稿への返信として1つだけ** 出す。
- 中身は「本文で書ききれなかった一言」＋「答えやすい問いかけ」。
- **ROOM・noteの日は、リンクの返信（2本目）とは別にしない**。リンクの返信がすでにある日は、行動①は出さない（1つの投稿に導線を重ねない・売り込み感を出さないため）。
- 商品・ROOM・noteに触れないのでPR不要。

下書き（型）
```
補足です。
【本文で書ききれなかった一言（体の仕組みで1〜2行）】
よかったら、【答えやすい問い】を返信で教えてください。
```

答えやすい問いの例（はい／いいえ、または2択で答えられるもの）
- 「やってみて、肩が下りた感じはありましたか？」
- 「座っている時間と、立っている時間、どちらが長い日が多いですか？」
- 「気づいたときに、もう肩が上がっていたこと、ありますか？」

注意
- 問いは **2択か、ひとことで答えられるもの** にする（「どう思いますか？」のような広い問いは答えにくい）。
- 来週12/2の「朝・昼・夕方・夜」の問いと重ねないよう、今週は **時間帯を聞く問いは使わない**。
- 「治る」「改善する」「効く」「必ず」は使わない。読む人の原因を決めつけない（「〜こともあります」の形）。
- 本文の中身（10 投稿文担当の確定版）が出たら、【 】の中を各日の本文に合わせて埋める。25がまだ埋めていないのは、今週の本文が **未作成** のため。

### 行動② 返信をくれた人へ「お礼＋相手の言葉をひとつ返す＋小さな問い返し」

ねらい：返信に1往復で終わらず、もう一言もらいやすくする。返信をくれた人に「ちゃんと読んでもらえた」と感じてもらう。

下書き（型。型Aに足して使う）
```
ありがとうございます。
「【相手の言葉を短くそのまま】」、わかります。【短い答えか共感を1行】
【小さな問い返し】
```

例（想定。実際に届いた返信ではない）
- 相手「やってみたら肩が下がりました」
  ```
  ありがとうございます。
  「肩が下がった」、うれしいです。下がったぶん、知らないうちに上がっていたのかもしれませんね。
  お仕事中は、座っていることが多いですか？
  ```
- 相手「いつも肩がガチガチです」
  ```
  ありがとうございます。
  「いつもガチガチ」、つらいですよね。同じ姿勢が長く続くと、そう感じやすいんです。
  一日のなかで、とくに重く感じる場面はありますか？
  ```

注意
- 問い返しは **1回まで**。相手が答えたら、次はお礼と短い一言で終わる（しつこくしない）。
- 相手の言葉をくり返すときは、名前・住んでいる地域・仕事先など **個人が分かる部分は入れない**。
- しびれ・強い痛み・頭痛・「私の原因は？」には、問い返しをせず **型Dだけ** を返す。
- 問い返しの答えで導線を出すのは、相手が自分から「もっと知りたい」「何を使ってる？」と言ったときだけ（型B・C）。

### 行動③ 数時間たっても返信がないとき、自分の投稿へ「選びやすい問い」を1回だけ足す

ねらい：本文の問いが答えにくかったときに、もっと答えやすい形で、もう一度だけ声をかける。

出し方
- 投稿から数時間たって、返信が0件のときだけ。**1つの投稿に1回まで**。
- 行動①を出した日は、①と同じ問いはくり返さない（別の聞き方にする）。
- 導線（ROOM・note）は入れない。PR不要。

下書き（型）
```
ちなみに、私のところでは【よく聞く場面を1つ】という声をよく聞きます。
みなさんは、AとBなら、どちらが近いですか？
A：【選択肢A】
B：【選択肢B】
```

例（想定）
```
ちなみに、「気づいたら肩が上がっていた」という声をよく聞きます。
みなさんは、AとBなら、どちらが近いですか？
A：肩が重い
B：首がつまる感じ
```

注意
- 「よく聞きます」は、本人の臨床の実感にもとづく言い方（C＝臨床の視点）。**本人の実感と合わないときは、この1行を消す**（要確認）。数字（「○割の人が」など）は入れない。
- 「AとBのどちらが近いか」で、その人の原因を決めつけたり、診断の形にしたりしない。答えてもらったら、行動②の型でお礼を返す。
- 選択肢に「しびれ」「激しい痛み」など強い症状を入れない（選んだ人には型Dを返すことになるため）。
