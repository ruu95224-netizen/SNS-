## 1. 枠ごとの締めの一言（方針と文例）

### 1-1. 信頼枠（3本）｜導線なしの締め
**方針**
- リンク・プロフィール・note・ROOMへの誘導は入れない。
- 締めは「持ち帰れる一言」か「臨床の視点の一言」で終える（読んだ人が今日1つ試せる、または見方が1つ変わる）。
- 臨床の視点（「現場では〜」）は根拠の強さC。本人が台本確定（★承認2）で確認するまで「仮」。
- 強い症状（しびれ・強い痛み・頭痛）に触れた投稿は、締めの前に受診をすすめる一文を入れる。
- ROOM投稿の前振りになる信頼投稿（27のNo.5）でも、締めで道具やROOMを匂わせない（「おすすめの道具はまた紹介します」も書かない）。

**文例（10が投稿の中身に合わせて選び、言い回しを変える）**
- 「肩をもむ前に、まず同じ姿勢の時間を区切る。それだけでも、首肩の負担のかかり方は変わりやすいんです。」
- 「つらさの原因は一つとは限りません。今日は『目』のほうも少し休ませてみてください。」
- 「姿勢は正しく保つより、こまめに変えるほうがラクになりやすい。現場ではそう感じることが多いです。（臨床の視点：本人確認）」
- 「次に肩が重いと感じたら、まず時計を見てみてください。どのくらい同じ姿勢だったかが、ヒントになります。」
- （強い症状に触れた場合の一文）「しびれや強い痛みがあるときは、セルフケアより先に医療機関で相談してくださいね。」

**使わない締め**：「フォローしてね」「保存必須」「続きは明日」「プロフィールのリンクから」「詳しくはnoteで」

### 1-2. 交流枠（2本）｜答えやすい問い
**方針**
- 問いは**1つだけ**。一言・選択肢で答えられる形にする（例：「AかBで教えてください」）。
- 本文に導線は置かない。返信が来たら25の型で答える（基本は型A＝答えて終わる。深掘りを求められたら型B＝note、道具を聞かれたら型C＝ROOM・PR）。
- 問いは「診断を求められる形」にしない（「あなたの原因はどれ？」は×）。
- 2本の問いは種類を変える：1本は「場面・時間帯」系（会話が広がる）、1本は「道具・買い物」系（ROOMの材料が集まる。ただし本文で商品名は出さない）。
- 道具系の問いでも、本文で商品名・ROOMに触れなければPRは不要。商品名を出すならPR必須（15が判断）。

**文例（05のP1〜P5を土台に、言い回しを調整）**
- 場面・時間帯系
  - 「肩こり、いちばんつらいのは朝・昼・夕方・夜のどれですか？一言で教えてもらえるとうれしいです。」
  - 「寒い朝、肩がすくんでいるのに気づくのは、家ですか？通勤中ですか？」
  - 「在宅とオフィス、肩がこりやすいのはどっちですか？」
- 道具・買い物系
  - 「肩こり対策で買ったけど、使わなくなったもの、ありますか？」
  - 「肩こりのグッズ選び、いちばん迷うのは『種類』『値段』『続くか』のどれですか？」

**締めのあとに足してよい一言（任意）**：「返信は一言でも大丈夫です。」（押しつけにならない範囲で。毎回は付けない）

### 1-3. ROOM枠（1本）｜仕組み → 選び方の基準 → ROOM（PR必須）
**方針**
- 本文の流れ：1行目（場面・困りごと）→ なぜラクになりやすいか（体の仕組み）→ 選び方の基準 → 締めでROOMの場所を伝える。リンクは2本目。
- **本文の先頭行に「PR」**。
- 締めは「選んだものを置いている場所を伝える」だけにする。「買ってください」「おすすめです」「売り切れ前に」は書かない。
- 「楽天ROOMで紹介中」と書けるのは、**投稿日の前日までに本人がROOMに載せたことを確認できた商品だけ**（`threads/room-items.md` に記録）。載っていなければ3章の差し替え文を使う。
- ROOM投稿は週後半（06が日付を決める）。note枠と連続した日にしない（2日続けて導線になるのを避ける）。

**本文の締め（商品ごとの文例。06が選んだ1点に合わせて10が使う）**
- ノートPCスタンド＋外付けキーボード
  - 「この基準で選んだスタンドとキーボードを、楽天ROOMにまとめています。リンクは返信欄に置いておきます。」
- 首肩用の温熱パッド（レンジで温めるタイプ）
  - 「温めて一息つく時間をつくる道具として、選んだものを楽天ROOMに置いています。リンクは返信欄にあります。」
- 蒸気のホットアイマスク
  - 「画面を見たあとに目を休める道具として、選んだものを楽天ROOMに置いています。リンクは返信欄にあります。」

**注意（07・10・15へ）**
- 温熱パッド・アイマスクは「温めると血流がよくなって治る」と書かない。「休むきっかけ」「目を休める時間をつくる」の視点で。
- PCスタンドは「正しい姿勢を保つ」と書かない。「うつむく時間を減らす」「同じ姿勢を続けにくくする」。
- 商品ページの区分で「医療機器」と表示されていないことを確認してから紹介する（貼るタイプの温熱シートは選ばない：01のM10）。
- 価格・レビュー数は、本人か14が楽天のページで確認したものだけ。

### 1-4. note枠（1本）｜無料noteの「読む理由」をつくる
**方針**
- 本文は1本で役に立つ形にし、そのうえで「全体のつながり」「なぜそうなるか」をnoteで読める、と伝える。結論を隠して「続きはnoteで」にしない。
- 有料note（2027年4月ごろ予定）の核心（具体策）はThreadsで出さない。
- 「無料で読める」ことを書く。読む時間・文字数などの数字は、本人が無料noteを確認するまで書かない。
- 昼休みに読む人が多い想定（05のR5・推定）なので、「あとで読める」前提の言葉が合う。
- 今週の「読む理由」の切り口は**場面型**を提案（例：夕方、画面を見ていると首の付け根が重くなる）。27の仮説H3（場面型／誤解型の比較）の1回目として、使った切り口を記録する。

**本文の締め（文例）**
- 「なぜ戻りやすいのか、全体のつながりは無料のnoteにまとめています。リンクは返信欄に置いておきます。」
- 「今日の話の『なぜ』の部分を、無料のnoteに少し詳しく書きました。気になったら、夜にでも読んでみてください。」
- 「首だけでなく、目や座っている時間とのつながりも、無料のnoteで整理しています。リンクは返信欄にあります。」
  - ※どの文例を使うかは、無料noteの中身が分かってから決める（noteに書いていないことを「まとめています」と言わない）。

## 2. ROOM枠の2本目（自分の投稿への返信）の定型文

### 2-1. 通常版（本人がROOMに載せたことを確認できた日）
```
PR
今回の基準で選んだ【商品名またはカテゴリ】は、楽天ROOMにまとめています。
【ROOMのURL】
※楽天ROOMのリンクです（アフィリエイトを含みます）。
選ぶときは「【選び方の基準を一言で】」を目安にしてみてください。
```
- **1行目に「PR」**（2本目だけが単独で表示されることがあるため。02の提案）。
- リンクは1本だけ。ROOMのトップより、**その商品（またはその商品を入れたコレクション）のページ**を置く案を基本にする（どちらにするかは11のコレクション名と本人の作業しだい）。
- 「リンクから買ってもらえると…」のような購入のお願いは書かない（01のM7：見返りつきの購入依頼は禁止とされている）。
- 最後の1行（選び方の基準）は任意。2本目だけを見た人にも役に立つように入れる案。

**商品ごとの差し込み例**
| 商品 | 【商品名またはカテゴリ】 | 【選び方の基準を一言で】 |
|---|---|---|
| ノートPCスタンド＋外付けキーボード | ノートPCスタンドと外付けキーボード | 画面の高さを何段階か変えられること・キーボードと一緒に使えること |
| 首肩用の温熱パッド | レンジで温める首肩用のパッド | 首から肩にのせやすい形か・手入れが続けやすいか |
| 蒸気のホットアイマスク | 蒸気のホットアイマスク | 寝る前など、毎日使う時間を決めやすいか |
※基準の中身は07・10が本文と合わせて決める。上は仮の例（臨床の視点として本人確認が必要）。

### 2-2. 差し替え版（本人がROOMに載せていなかった日）
**基本は「リンクなし・導線なし」版にする**（ROOMに載っていない商品へ誘導しないため）。

**差し替え版B（推奨）：導線なし**
- 本文：先頭の「PR」と、締めのROOMの一文を**削除**し、下の締めに置き換える。商品名を出していないことを15が確認する（商品名が残るならPRも残す）。
  - 本文の締め：「道具を選ぶなら、まずこの基準だけ覚えておいてください。高い物より、毎日使い続けられる物のほうが役に立ちやすいんです。」
- 2本目（任意。付けるならリンクなし）：
```
選ぶときの目安をもう一度まとめると、
・【基準1】
・【基準2】
自分の机・生活に合うかどうかで決めてみてください。
```

**差し替え版A（任意）：ROOMに追加予定と伝える（リンクなし）**
- 本人が「数日以内に必ず載せる」と決めている場合だけ。
```
PR
今回の基準で選んだ【商品名またはカテゴリ】は、楽天ROOMに追加する予定です。
載せたら、この返信欄でお知らせします。
```
- 追加後に本人が同じスレッドへ2-1の通常版を返信として足す（送信は本人）。
- 予定どおり載せられないと約束を破る形になるため、迷ったら差し替え版Bを使う。

**10・23への依頼**：ROOM枠の投稿は「通常版」と「差し替え版B」の2つを完成形で用意し、`投稿文_コピー用.txt` に並べる。23の予約前チェックリストに「ROOMに載っているか（`threads/room-items.md`）」を入れる。

## 3. note枠の2本目の定型文（【無料noteのタイトル】【URL】差し込み式）

### 3-1. 版①：noteの中にアフィリエイトリンクがない場合（PR不要）
```
無料で読めるnoteです。
「【無料noteのタイトル】」
【URL】
【この記事で分かることを一言で】
```
- 自分のnoteへのリンクだけなので、PRは不要（25の表と同じ扱い。最終判断は15）。
- 3行目（分かること）は、本人がnoteの中身を共有してから11・10が書く。分からないうちは削る。

### 3-2. 版②：noteの中に楽天アフィリエイト等のリンクがある場合
```

無料で読めるnoteです。
「【無料noteのタイトル】」
【URL】
```
- note側の記事にもPR表記が必要（`rules/ng-expressions.md`、01のM14）。note側の表記の有無は本人が確認する。
- 本文（1本目）にもPRを付けるかは**要確認**（15が判断）。安全側の案は「1本目の先頭にもPR」。

### どちらの版を使うか

- 回答があるまでは、10は**両方の版**を用意する。回答で使わない方を消す。

## 4. プロフィールのリンク（ROOM・note）の並べ方の提案

### 前提
- Threadsのプロフィールに置けるリンクの数：**不明**（複数置けるようになったという報道はあるが未確認。02・27）→ **要確認（本人の画面で確認／14が公式で確認）**。
- ROOMは今0点。中身がないページへの入口は置かない。

### 提案
| 置けるリンク数 | 並べ方（上から） | 理由 |
|---|---|---|
| 2本以上 | ①無料note ②楽天ROOM（表示名に「PR」を入れる。例：「PR｜楽天ROOM（使っている道具）」） | noteは「信頼→有料noteの読者をためる」入口で、プロフィール文の流れ（10章案「深掘りはnoteで」）と合う。ROOMは投稿を見逃した人の入口。並びの効果（どちらが押されやすいか）は不明 |
| 1本だけ | 無料noteのみ。ROOMへは投稿の2本目と返信（25の型C）で案内する | 10章のプロフィール案と同じ。ROOM0点の今はnoteを優先 |
| — | ROOMのリンクを置くのは、**本人がROOMに3点載せてから** | 0点のページに誘導しない |

- リンク集のサービス（lit.link等）でまとめる案もあるが、外部ツールの利用になるため今週は提案しない（使う場合は本人の承認が必要）。
- ROOMのリンクをプロフィールに置く場合、プロフィール文か表示名に「PR」を入れる案を基本にする（要否は15が判断）。

### プロフィール文についての気づき（本人作業・任意）
- `docs/ruru-strategy.md` 10章のThreadsプロフィール案に「なぜ効くのか」がある。商品紹介をする今、「効く」は避けたい表現（`rules/ng-expressions.md`）なので、「なぜラクになりやすいのか」への言い換えを提案する（変更は本人が判断）。
